# 3. Label Generator for Furniture Production

**Описание:** Программа для автоматизированного создания этикеток на упаковку для мебельного производства. Приложение позволяет искать заказы в файле раскроя, просматривать информацию о них и генерировать готовые Excel-файлы с этикетками по заданным шаблонам.

**Технологии:** Python, PyQt6, pandas, openpyxl, Excel

**Основные возможности:**
- Загрузка и парсинг Excel-файлов с данными о заказах
- Поиск заказов по номеру с отображением всей технической информации
- Поддержка различных типов этикеток (корпус, фасады МДФ, фасады пластик и др.)
- Визуальный редактор данных этикеток перед генерацией
- Автоматическое форматирование Excel-файлов по заданным шаблонам
- Вставка логотипов и служебной информации в этикетки
- Настройка размеров ячеек, шрифтов и границ
- Сохранение истории настроек между сессиями

**Особенности реализации:**
- Применение принципов ООП с использованием абстрактных классов
- Модульная архитектура с разделением логики загрузки данных, обработки и UI
- Гибкая система редактирования параметров этикеток
- Поддержка пакетной генерации нескольких этикеток в одном файле
- Автоматический расчет номеров упаковок и дат отгрузки
- Валидация входных данных и обработка ошибок
